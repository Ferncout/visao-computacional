# 👁️ Visão Computacional

Repositório centralizado para o desenvolvimento de projetos, exercícios e implementações práticas na área de Visão Computacional, com foco em algoritmos baseados em princípios fundamentais (*first-principles*).

---

## 📂 Estrutura do Repositório

* **`/aula/assignment_1`**: Simulação interativa em PyQt5 de modelagem de corpo rígido, projeção perspectiva 3D-2D e manipulação de câmeras virtuais com matrizes de transformação homogênea.
* **`/aula/assignment_2`**: Implementação de ponta a ponta de estimativa de homografia planar utilizando **DLT Normalizado** e decomposição SVD do zero, integrado com SIFT, FLANN e RANSAC.

---

## 🛠️ Stack Tecnológica

* **Linguagem:** Python
* **Computação Numérica:** NumPy
* **Processamento de Imagem:** OpenCV
* **Visualização e Interface:** Matplotlib, PyQt5
